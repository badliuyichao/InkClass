📺 哔哩哔哩视频嵌入研究

结论：B站官方提供「站外播放器」，用 iframe 即可直接在页面内播放，无需跳转。

1核心方案：官方外链播放器

B站官方文档地址 player.bilibili.com，把普通视频链接里的 BV号 填进 iframe 的 src 即可：

<iframe src="https://player.bilibili.com/player.html?bvid=BV1zg4y157Gy&autoplay=0"
        scrolling="no" frameborder="no" allowfullscreen="true">
</iframe>
参数说明
bvid视频 BV 号（与 aid 二选一）必填
page / p多P视频的第几集，从 1 开始
autoplay是否自动播放（建议 0）
danmaku0 = 关闭弹幕
t从第几秒开始播放
muted是否静音
high_quality1 = 默认高清晰度
isOutside=true分享按钮生成的参数，可选
⚠️ 注意
  • 未登录观看者最高 360P/480P 清晰度（清晰度由B站控制，嵌入端无法突破）。
  • 部分视频（如充电专属、某些番剧）UP主设置了禁止转载嵌入，会显示「视频不可见」，换视频即可。
  • iframe 播放器右下角保留「进入哔哩哔哩观看」入口，这是官方规则，无法去除。

3方案A：响应式 16:9 自适应（推荐）

  
纯 CSS 等比缩放，手机/平板/电脑都不出黑边。就是本页预览用的方案。


/* CSS：16:9 等比容器 */
.bili-frame{position:relative;width:100%;padding-top:56.25%;
            border-radius:12px;overflow:hidden;background:#000}
.bili-frame iframe{position:absolute;inset:0;width:100%;height:100%;border:0}

/* HTML */
<div class="bili-frame">
  <iframe src="https://player.bilibili.com/player.html?bvid=BV1zg4y157Gy&autoplay=0"
          scrolling="no" frameborder="no" allowfullscreen="true"></iframe>
</div>







  
4方案B：封面懒加载（页面更快，点图才加载播放器）

  
一个页面放多个视频时，iframe 全部加载会很慢。先用封面图占位，点击才注入 iframe。👇 下面是真实效果，点击试试：

  点击封面后才开始加载播放器
  

  
  
封面图地址格式：http://i0.hdslb.com/bfs/archive/BV号去掉前两位.png（部分视频可用，不可用时可退回默认封面或自截图）。


function loadBili(container, bvid){
  container.innerHTML =
    '<iframe src="https://player.bilibili.com/player.html?bvid=' + bvid +
    '&autoplay=1" scrolling="no" frameborder="no" allowfullscreen="true"></iframe>';
}
