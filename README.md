# InkClass

InkClass 是一个面向小学五年级语文教学的数字化项目，由家长驱动，为孩子构建"教材 + 视频 + 写作"三位一体的学习资源库。

纯静态站点，零依赖，克隆即用：直接用浏览器打开 HTML 文件即可。

## 核心内容

- 📚 **教材资料**：五年级上册语文教材的数字化整理与知识点归纳
- ✍️ **写作指导**：漫画式写作教学法，如"漫画老师"单元写作提纲
- 🎬 **视频化学习**：基于 B 站优质内容的调研筛选，探索网页内嵌视频的最佳实践

## 项目结构

```
InkClass/
├── 五上语文第二单元/            # 第二单元互动课文页面（含配图与各单元 JS）
├── 漫画老师写作提纲.html        # 习作"漫画老师"写作指导
├── 五上语文B站视频调研报告.html  # B站配套视频调研
└── bilibili视频嵌入研究.html    # B站视频嵌入技术验证
```

## 快速开始

```bash
git clone ssh://git@ssh.github.com:443/badliuyichao/InkClass.git
# 打开任一 .html 文件，或用本地静态服务器预览
python -m http.server 8000
```
